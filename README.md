## About

Insomnia is a free, open-source REST and GraphQL API client for Windows, macOS, and Linux. Design, test, and debug APIs with an organized workspace of saved requests, environment variables, authentication helpers, and response visualization. Insomnia's Git sync feature allows version-controlling API collections. After Kong's acquisition it remains a popular open-source alternative to Postman.

## Common Problems & Limitations

- **Enterprise Changes** — Post-Kong acquisition introduced cloud login requirements, walked back by community pressure
- **Sync Features** — Local projects available; cloud sync requires account
- **Plugin Ecosystem** — Smaller than Postman's ecosystem
- **GraphQL Tooling** — GraphQL support good but less comprehensive than specialized GraphQL clients
